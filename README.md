# 📊 Customer Churn Analysis

A Data Analytics project focused on analyzing customer churn patterns, customer retention, and subscription behavior using Google Sheets.


## 📌 Project Overview
This project analyzes customer data to identify churn patterns and understand factors associated with customer retention and customer loss.

## 🎯 Objectives
- Analyze customer churn and retention.
- Identify churn patterns across contract types.
- Compare churn across subscription plans.
- Explore customer behavior and payment patterns.
- Visualize insights using charts.

## 📂 Dataset Information
- Total customers analyzed: 600
- Duplicate records removed: 5
- Missing region values handled using "Unknown".
- Unknown Total Charges values retained without guessing.

## 📈 Key Results
| Metric | Value |
|---|---:|
| Total Customers | 600 |
| Churned Customers | 247 |
| Retained Customers | 353 |
| Churn Rate | 41.17% |
| Retention Rate | 58.83% |

## 📊 Contract Analysis
| Contract Type | Churn Rate |
|---|---:|
| Month-to-Month | 59.81% |
| One Year | 20.12% |
| Two Year | 20.83% |

Month-to-month customers show a higher churn rate than customers on longer-term contracts.

## 📦 Subscription Analysis
| Subscription | Churn Rate |
|---|---:|
| Pro | 40.48% |
| Standard | 42.46% |
| Basic | 40.76% |

## 💡 Recommendation
- Encourage customers to choose longer-term contracts.

- Monitor customer churn trends regularly.

## 📝 Conclusion
The analysis reveals that contract type is an important factor associated with customer churn. Month-to-month customers have a considerably higher churn rate than yearly contract customers.
